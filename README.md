# SPATIAL BLACKOUT

**Find the impostor before you run out of time!**

## Chosen themes

- Running Out of Time
- Dark / Light

## Description

There is a group of aliens on screen. Among all of them, there is one who is different from the rest.\
Your mission is to find the alien, but beware! There is a limited period of time to do it, and the more progress that you make, the difficultier that the game will get.\
From time to time, there will be a blackout. That means that you won't be able to see anything for a few seconds.

## How does this game work?

There is a frame in which there is a group of aliens floating.\
In this group, there are several copies of 3 types of aliens and a unique copy of a different one.

You have to look for the alien that is diferent from the rest and click it. There is a counter that tells you how much time you have to do it.
- If the counter reaches zero:
  - You lose.
- If you find the alien before you run out of time:
  - You get 1 point and 5 extra seconds.
  - A new group of aliens gets instantiated.
  - The number of members in the group will grow, so it will be more difficult to find the alien.

From time to time, a black image will overlap the frame in which the aliens are positioned (the blackout), so you won't be able to see for a few seconds.

## How is this game related to the chosen themes?

- **Running Out of Time:** There is a limited period of time to find the alien, so you are literally "Running Out of Time".
- **Dark / Light:** There is a blackout that happens from time to time, that means that there is a different between when it is dark and when there is light.
